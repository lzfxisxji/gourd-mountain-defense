# 守护葫芦山 · Windows 桌面版

当前正式版本为 0.2.0，推荐下载支持自动更新的安装版：

https://github.com/lzfxisxji/gourd-mountain-defense/releases/latest

安装包文件名为 GourdMountainDefense-Setup-0.2.0-x64.exe。双击安装后从桌面快捷方式启动，游戏本身离线可玩，不需要浏览器、Node.js 或本地服务器。

## 更新与存档

启动 5 秒后自动检查版本，运行期间每 6 小时检查一次，也可点击菜单右上角“检查更新”或战斗工具栏“更新”。发现新版后可查看更新说明，选择下载；下载完成后点击“保存并重启更新”。程序先保存战局，再运行安装包并重启。关闭游戏不会擅自安装已下载的更新。网络失败可重试，旧版本仍可游玩。

更新源固定为 lzfxisxji/gourd-mountain-defense 的 GitHub Releases。只接受高于当前版本的正式版本，校验安装包 SHA512，不向玩家程序写入 GitHub Token。免安装版不能原地自动升级，使用自动更新前须安装上述安装版一次。

所有桌面版本的存档保存在当前 Windows 用户的 %APPDATA%\GourdMountainDefense。升级或替换程序不清除它。网页版存档可在左上角“读取存档”导出 JSON，然后在桌面版相同位置导入。存档属于当前电脑和 Windows 用户，没有云同步。

F11 切换全屏，Esc 退出全屏。战斗中每 10 秒自动保存；暂停、返回菜单或正常关闭窗口也会保存。

## 后续发布

1. 修改角色、关卡或玩法，运行 npm test。
2. 更新 package.json 和 package-lock.json 的版本号，提交并推送到仓库。
3. 给该提交打版本标签，例如 v0.2.2，再推送标签。
4. GitHub Actions 的 Windows release 工作流会测试、打包并发布安装包、blockmap 和 latest.yml，现有安装版即可检测更新。

标签必须和 package.json 版本一致；不要重复使用旧版本号。QA 专用 0.2.1 只做本地升级测试，不发布到正式更新源。

本地打包可双击“重新打包EXE.cmd”或执行 npm run build:exe。安装版产物在 release/版本号；npm run build:portable 生成免安装版。npm run desktop 启动开发桌面版，开发状态不自动检查更新。

桌面检查：node tests/desktop-smoke.cjs release/0.2.0/win-unpacked/GourdMountainDefense.exe。
完整升级检查：先以 electron-update-test.yml 构建 QA 安装包，再运行 node tests/update-e2e.cjs，测试使用独立临时存档和 QA 安装标识，不发布测试版本。

# 葫芦兄弟 · 守护葫芦山

已实现 1-1 ～ 1-10 与 2-1 ～ 2-5 共十五关。第一章使用葫芦藤园地图，第二章使用蛇精老巢洞府地图；两章沿用五行九列战场。美术为生成素材，人物以独立透明图集渲染。

## 运行

需要 Node.js 18 或更新版本，无需安装依赖。当前目录运行 `npm start`，浏览器打开 http://127.0.0.1:4173 。也可双击“启动游戏.cmd”。

## 操作

- 点击角色卡片，再点击空格放置。1、2 键也可选卡。
- 点击金色灵气球增加 25 灵气；四娃 100 灵气，葫芦藤 50 灵气；冷却均为 7.5 秒。
- 角色自动攻击。四娃 20 单体伤害、1.4 秒间隔，无额外灼烧；青蛙精 200 生命、100/秒近身攻击。
- 葫芦藤首次 8 秒产出，此后每 24 秒产出 25 灵气；天空定期掉落灵气。
- 右键或 Esc 取消放置，S 切换铲子，空格暂停；页面切到后台自动暂停。
- 每条开放路线一个滚动葫芦，触发后一次清场；之后敌人突破会失败。
- 1-1 开放中央一行，通关解锁葫芦藤与 1-2；1-2 开放中间三行，通关解锁三娃。三娃从 1-3 起可上阵。
- 1-3 开放五行并使用黄色三娃防守，通关解锁哪吒；1-4 使用哪吒，通关解锁穿山甲；1-5 加入穿山甲，通关解锁红色大娃，1-6 起可上阵。
- 哪吒：150 灵气，卡片冷却 50 秒。放置后等待；点击场上哪吒，再点击目标区域中心，发射 3×3 火焰，区域内造成 1800 伤害；附近出现妖怪时自动对自身周围释放。每次放置只释放一次，随后退场。右键或 Esc 取消瞄准；只伤害草坪上的妖怪，不伤害己方角色。
- 穿山甲：25 灵气，冷却 30 秒，地下准备 14 秒后探头待命；本行妖怪靠近时触发近距离范围攻击，1800 伤害，使用后退场。未准备时不能攻击，且可被妖怪攻击。
- 战场右上角“保存”可保存当前战局；游戏每 10 秒自动保存，暂停、返回菜单、离开页面时也会保存。主菜单左上“读取存档”可以继续保存的战局，并导出或导入 JSON 备份。记录包含时间、灵气、角色、妖怪、弹丸、减速、冷却、葫芦使用状态及随机事件序列。旧版通关记录自动迁移。
- 存档保存在当前浏览器 localStorage；无效导入文件会被拒绝并保留已有存档。浏览器不允许写入时会显示保存失败。
- 主菜单右侧闯关编号随进度变化：优先显示保存战局的关卡，否则显示下一关；点击进入该关选角或直接恢复已保存战局。左上“读取存档”显示当前关卡、十五关进度、已解锁角色、保存时间，并支持恢复战局与导入/导出。
- 五娃已实现水弹攻击：175 灵气、20 单体伤害、1.4 秒攻击间隔；命中后移动和近身攻击节奏降至一半，持续 10 秒，重复命中刷新时长而不叠加幅度。按原版解锁顺序，通关 1-6 后获得，1-7 起可用；已开放对应关卡，可在开局选角时携带。
- 无尽和趣味挑战尚未开放。
- 浏览器通常不允许网页关闭用户手动打开的标签页，退出会停止游戏并显示可关闭提示。

## 扩展

`src/engine.js` 的 CHARACTERS 管理角色，`src/levels.js` 管理关卡；source 字段标注所属作品，可继续添加其他上美影角色。射手、资源生产、阻挡、玩家瞄准的范围技能及伏击职责已分离。

`npm test` 执行战斗规则、阵容限制、存档与关卡可通关测试。普通运行不暴露测试入口，`?qa=1` 仅供浏览器集成验证。

## 商店、金币与卡槽

初始 6 槽，按顺序升级：7 槽 750、8 槽 5,000、9 槽 20,000、10 槽 80,000 金币。价格来源：[EA 原版说明](https://akamai.cdn.ea.com/eadownloads/u/f/manuals/GAME-PVZ/en_US_readme.html)。商店位于菜单下方图鉴左侧，随时可查看余额和升级条件。

本改版经济规则：妖怪死亡有 35% 概率掉钱，其中 80% 是银币（10）、20% 是金币（50），点击收集，20 秒未收集消失。通关结算 250 金币，加上本关有效路线每个未使用的葫芦车 50 金币，并收取地面尚未消失的掉落。重玩通关也可赚取金币。金币与灵气独立，初始金币为 0；拾币、购买、通关后保存，导入导出包含余额与卡槽，兼容旧存档（默认 0 金币、6 槽）。

卡牌尺寸固定在卡栏内，未使用的位置显示空槽，升级增加卡栏容量，不会解锁新角色。当前十关提供九位实战角色；开局选角从已解锁角色中选择，最多携带当前卡槽容量，可少选且不能重复。默认阵容推荐葫芦藤与输出角色。选择顺序对应战斗卡牌顺序，战局存档保留阵容与容量，恢复时无需重选。首关只有四娃，直接进入教学。

1-6「巨力守关」加入大娃（125 灵气、8000 生命），37 只妖怪，通关解锁五娃；1-7「碧水退妖潮」加入五娃，43 只妖怪。两关继续使用第一章木境地图。1-7 完成后解锁七娃，1-8 可上阵；1-8 通关后解锁二娃，1-9 起可上阵。

选卡页采用战前布阵布局：上方是已选卡栏，左下是角色卡册，右侧预览本关妖怪与数量。初始阵容为空，点击下方卡牌加入、点击上方卡牌撤回；也可使用推荐阵容。开始战斗按钮在未选角色时禁用。

蝙蝠精：300 生命，1-6 与 1-7 混编出现；飞行速度 20，越过地面角色，不进行近身攻击，也不触发穿山甲。四娃与五娃可对空攻击，五娃减速和哪吒火焰生效，葫芦车可清除同路低空敌人。图鉴含外观、属性、行为和振翅演示，选卡页预览真实敌人种类。

新增关卡：1-8「空陆夹击」、1-9「妖洞前哨」、1-10「决战蛇精」，全部沿用第一章木境地图、开局选角和金币存档。蛇精在 1-10 与 2-5 登场，生命 1000、速度 10、近身攻击 100/秒。对哪吒火焰或穿山甲伏击，每次最多承受 500 伤害，满血需两次爆炸（可混用）；其他妖怪仍承受原爆炸伤害。普通弹丸伤害、水弹减速正常。图鉴与选卡敌人预览均包含蛇精。1-8、1-9、1-10 通关奖励金币及进度，1-10 通关后继续进入第二章 2-1。

蛇精冻结技能：从登场开始每 40 秒随机选择一位存活、未退场且未被冻结的角色，冰封 8 秒。被冻结时暂停攻击、灵气产出、穿山甲准备和哪吒手动/自动施法，但仍阻挡敌人并承受伤害，也可铲除。卡片冷却、已发射弹丸和已释放技能照常运行。无有效目标时跳过该次施法，下一次仍在 40 秒后；蛇精死亡后不再施法，已有冰封到时解除。暂停游戏同时暂停倒计时，存档保留冻结剩余时间、施法冷却及随机状态；旧战局缺失冻结字段时默认未冰封，旧蛇精首次恢复默认冷却 40 秒。

战斗左上新增倍速滑块：1× / 1.5× / 2×，同步加速出怪、移动、攻击、资源产出、冷却与冻结等技能计时，暂停仍停止战斗。通过不大于 0.05 秒的子步推进以保持碰撞及攻击判定稳定。倍速偏好随设置自动保存并支持导入导出；旧存档默认 1×。UI 提示和音效仍按正常播放时长。

七娃已实装：150 灵气、300 生命、7.5 秒卡片冷却，吸收本行前方 1 格内的单个地面普通妖怪，随后炼化 42 秒；不吸收蝙蝠精与蛇精。炼化期间仍可受伤，冰封暂停炼化计时。二娃已实装：200 灵气、300 生命、7.5 秒卡片冷却，每轮 1.4 秒，两发金光弹相隔 0.14 秒，每发 20 伤害，可对空。阵容、炼化倒计时、双发中的待发弹都可存档恢复。旧进度通关 1-7/1-8 后自动开放对应角色。

商店改为木制货摊、双层货架和爷爷掌柜，掌柜按用户两张参考图重绘，去除锄头、背篓与草帽。商品可点击查看，已购/后续商品均明确标识；金币、卡槽价格与顺序购买逻辑保持。

图鉴采用分类目录、头像网格和左右分页详情布局：入口选择角色/妖怪，内页左侧浏览九位伙伴或三种妖怪，右侧展示完整形象、属性与技能，底部可返回目录或关闭。统一按素材边界适配绘制，避免长翅膀和伸展动作被裁切；保留未解锁提示及动作演示。手机横屏详情可在右页内滚动。

六娃已加入：对应窝瓜，50 灵气、30 秒卡片冷却，隐身待命无准备时间，自动跃起突袭附近地面目标及紧邻敌人，单次使用后退场。普通敌人受 1800 伤害，蛇精每次最多承受 500；蝙蝠精不会触发且不受突袭伤害。冻结时无法触发，已跃起攻击可存档恢复。通关 1-10 获得，可用于第二章及重玩关卡；旧存档已通关第一章也会自动开放。现有十位角色可在开局按卡槽容量选择，快捷键 0 对应第十张卡。

## Windows 桌面版与自动更新

[下载最新安装版](https://github.com/lzfxisxji/gourd-mountain-defense/releases/latest)。安装一次后可检查更新、查看说明、下载更新并保存战局后重启安装。游戏离线可玩，更新来自 GitHub Releases；免安装版需先安装此版本才能使用自动更新。

存档保存在当前 Windows 用户的 `%APPDATA%\GourdMountainDefense`，更新不清除存档，支持游戏内 JSON 导入/导出与网页版迁移。F11 切换全屏，Esc 退出全屏。

本地执行 `npm run build:exe` 或双击“重新打包EXE.cmd”生成安装版，输出在 `release/版本号`。`npm run build:portable` 生成免安装版。后续递增版本号、提交源码并推送对应 `v版本号` 标签，GitHub Actions 自动构建并发布安装包、blockmap、latest.yml。详见 [桌面版说明](desktop/使用说明.md)。

桌面验证：`node tests/desktop-smoke.cjs release/0.2.0/win-unpacked/GourdMountainDefense.exe`；升级验证：`node tests/update-e2e.cjs`，均使用独立测试存档。更新实现采用 [electron-updater 官方流程](https://www.electron.build/docs/features/auto-update/)，客户端不包含 GitHub 发布凭据。

1-10 新开战局为传送带 Boss 关：跳过选卡与灵气经济，空带开局，每五秒从右侧送入一张卡牌，缓慢向左滑动排队；使用后继续滑动补位，最多八张，满带等待。用掉一张才能部署一个角色，不受卡槽升级与种植冷却限制。保留蛇精及护卫波次。供卡与战局共用游戏时间，支持暂停、倍速和存档恢复；旧版 1-10 战局按普通模式恢复，重新开始才切换传送带。

## 舒克与空投控制

舒克通过累计签到第 4 天永久领取，替换当天原定的 5000 金币；已领取过旧版第四天金币的存档自动补发舒克，金币不扣回。200 灵气、300 耐久、卡片冷却 7.5 秒，每 4 秒自动向本行最靠前的可攻击妖怪发起空投，飞至目标上空后向下投掷，随后返回部署位置。地面近战不会攻击空中的舒克，蛇精仍可冻结他。

- 40% 渔网：本行两格宽范围，20 伤害（使用四娃火焰弹伤害值），禁止妖怪移动、攻击和施法 4 秒。重复控制刷新时长。
- 40% 石头：单体 50 伤害，存活目标向右击退半格（62 逻辑像素）。
- 20% 毒蘑菇：单体魅惑 10 秒，妖怪反向行进并攻击同路敌人；地面与飞行目标均可命中。魅惑到期后恢复敌方，离开右侧战场的盟友安全退场。蝙蝠精作为盟友时使用 20 点近身攻击。

空投在 0.8 秒后命中锁定位置，目标可移出范围躲避。己方射手、范围攻击、葫芦小车不会伤害魅惑盟友；敌方妖怪可与其交战。控制和魅惑仅用网罩、爱心、光圈和朝向变化表现，没有新增局内状态文字。旋翼、悬停、往返飞行和下落道具由 Canvas 动态绘制。素材为内置 imagegen 生成，保存至 `assets/animation/shuke-helicopter-poses.png`，完整提示词见 `docs/shuke-assets.md`。空投、控制剩余时长和魅惑阵营随战局存档恢复。

专项验证：`node --test tests/shuke.test.mjs`、`node tests/browser-shuke.cjs`。

# 哪吒、穿山甲与 1-3～1-5

生成方式：内置 image_gen。哪吒参考用户提供图片，参考图保留在 assets/sprites/nezha-reference.png。穿山甲和大娃沿用现有葫芦兄弟手绘动画风格。三娃的黄色旧素材未替换，继续使用 support-poses.png。

关卡顺序：1-3 使用三娃，解锁哪吒；1-4 使用哪吒，解锁穿山甲；1-5 使用穿山甲，解锁大娃。大娃后续上阵。五娃与七娃仍按 1-6、1-7 通关后的既定计划安排。

范围技能和地下准备计时会保存到战局快照，旧存档没有 spells 字段时补为空列表。原有 completed=0～2 的记录继续可用，当前支持 completed=0～5。

菜单闯关编号优先显示保存战局的关卡，否则显示下一关，已完成全部五关则显示 1-5。左上存档页的五关进度为只读展示，不新增选择关卡页。
